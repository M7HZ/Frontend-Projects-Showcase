## Interactive Project Approach
The live demonstrations focus on real client-side interactions rather than static mockups.

Depending on the project, this includes:
* Interactive navigation
* Forms and validation
* Modals and drawers
* Filtering and search
* Cart and quantity management
* Task state management
* Reservation flows
* Responsive layouts
* UI state changes
* Client-side data handling

Where a project does not have a production backend, the functionality is presented honestly as a client-side demonstration, prototype, or concept. No production database, payment gateway, healthcare system, commercial client data, or other backend service is implied unless explicitly implemented.

## Project Scope & Transparency
All featured portfolio work consists of personal projects, design concepts, prototypes, or academic coursework. These projects do not represent client work, commercial work, or professional UX employment.

Install dependencies:

\`\`\`

\`\`\`bash

\`\`\`

Create a production build:
